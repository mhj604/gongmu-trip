# 개발 기록

## 화면 구성 개선

2026-11-13 사용자 요청에 따라 화면을 간결하게 정리했습니다.

- 메뉴를 출장 정보·국내 출장·국외 출장·특수 여비·정산서·보관함·지급 기준·설정으로 표시합니다.
- 기본정보를 출장 개요·출장자·일정의 흰색 카드로 묶고, 부서·직위·예외 기준·비고는 펼쳐서 입력하도록 배치했습니다.
- 데스크톱에서는 우측 출장 요약, 좁은 화면에서는 아래쪽 요약을 제공합니다. 초기 입력 화면의 반복 금액 카드는 하나로 통합했습니다.
- 비용 표의 설명은 입력 안내로 옮기고, 상세 항목 토글로 세부 열을 표시합니다. 국내 출장에서는 불필요한 환율 탭을 표시하지 않습니다.
- 정산서에는 총액과 Excel·Word 다운로드를 먼저 보여 주며, 항목별 내역·계산 근거·확인 사항을 탭으로 나눴습니다.
- 계산 엔진과 정산 문서 생성 규칙은 유지했습니다.

## 배포 내용

2026-11-13에 한국어 Streamlit 로컬 앱, 독립 계산 엔진, 법령 자료집, SQLite 보존, Excel 및 Word 생성 코드를 작성했습니다. 공식 별표 원본은 지급등급·국내외 지급표·가족·이전·상시출장·비공무원 기준별로 보관합니다. 주요 판단과 실행·입력 안내는 README와 한글 문서에 기록했습니다.

법령 조사와 달리 프로그램의 품질 확인 절차를 별도 사용자 흐름이나 승인 단계로 만들지 않았습니다. 아래 기록은 개발 과정에서 수행한 실행 결과이며 정부기관의 법적 인증을 의미하지 않습니다.

## 실행 기록

- Python 3.12 환경에서 의존성 설치 및 실행 진입점 로드.
- 주요 법정 경계·공식 예시·문서·저장 사례 **43건 통과**.
- Streamlit 앱 로드, 국내 입력 화면, 정산 결과/다운로드 화면에서 예외 없이 동작.
- 생성된 Excel을 다시 읽어 9개 시트, 숫자 총액, 합계 수식 캐시와 원본 입력 보존 확인.
- 생성된 Word를 다시 읽어 공통 총액과 원본 입력, 외부 출처 관계 보존 확인.

## 남은 한계

Microsoft Excel·Word 데스크톱의 실제 인쇄 결과와 문서 렌더링 시각 확인은 수행하지 않았습니다. 자동 계산 미구현 항목과 자료 미탑재 기간은 [지원 범위](지원범위.md)에 별도로 기록했습니다. 첫 배포본의 코드 버전은 0.1.0이며 전체 요구사항 완료를 뜻하지 않습니다.


## 간편 입력과 Enter 입력 문제 수정

- 8개 메뉴와 단계 이동, 별도 일정 생성 버튼을 제거하고 입력과 결과를 한 화면으로 통합했습니다.
- 기본 입력은 출장 유형·날짜·출장지·숙박/교통 합계이며, 국외는 환율을 추가합니다. 개인 정보·등급·차량·증빙 등은 선택 입력으로 이동했습니다.
- 간편 합계는 기존 계산 엔진의 일정으로 변환합니다. 숙박비는 원 단위로 배분하고 마지막 행에 나머지를 보존하며, 배분 사실도 기록합니다.
- 국내 근무지 외는 사용자가 선택한 ‘다른 시군·왕복 12km 이상’ 구간을 명시적으로 지원합니다. 임의의 숫자 거리를 생성하지 않습니다.
- 예상 출장비와 확정 청구액을 분리했습니다. 예상 환율을 쓰더라도 실제 환율 증빙을 확인한 것으로 저장하지 않습니다. Excel·Word에도 예상액을 추가했습니다.
- Enter 후 값이 사라진 원인은 매 재실행마다 수정된 데이터를 표의 새 원본으로 넘겨 위젯 식별자가 달라지는 구조였습니다. 세션 내 편집 기준 데이터를 고정하고 계산용 Trip만 갱신합니다. 상세 입력 전환·기록 불러오기 때만 기준 데이터를 새로 만듭니다.
- 표 높이를 고정하고 금액·거리·시간에 숫자 열을 사용합니다. 문서번호는 문자열로 보존합니다.

## 자가용 간편 입력 연결

- 교통수단 선택을 추가 옵션에서 기본 화면으로 옮기고 자가용을 추가했습니다.
- 철도·버스 운임 준용과 연료비 방식의 입력을 나누어 기존 자가용 계산 엔진에 연결했습니다. 연료비는 거리·유종·단가·통행료·주차료로 산출하며 선택하지 않은 방식의 기존 입력을 중복 합산하지 않습니다.
- 연료비 계산 방식은 사유 텍스트와 분리하여 저장합니다. 사유·승인·증빙이 아직 없더라도 예상액을 계산하되 확정 지급으로 표시하지 않습니다.
- 동승자 제외와 근무지 내 별도운임 제외를 유지했습니다. 대중교통 운임 미입력은 0원과 구분합니다.
- 상세 교통 표에서도 자가용 계산 항목을 펼쳐 입력할 수 있습니다. 실행 중 열이 추가되었을 때만 편집 기준표를 갱신하며 일반 Enter 입력 시에는 유지합니다.

## 실행 화면 갱신과 상단 제목 여백

- 실제 브라우저에 이전 교통수단 화면이 남아 있는 것을 확인하고 서버를 최신 코드로 다시 실행했습니다. 실행 중 코드 변경이 화면에 반영되도록 Streamlit의 `server.runOnSave`를 켰습니다.
- 상단 고정 헤더와 제목이 겹치던 원인은 좁은 화면의 본문 상단 여백이 헤더 높이보다 작았기 때문입니다. 데스크톱과 모바일의 상단 여백을 확보하고 제목 행간을 조정했습니다.
