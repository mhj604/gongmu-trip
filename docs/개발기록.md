# 개발 기록

## 화면과 공식 정산서 서식 정리

2026-11-18: 출장별 요약을 하나의 카드 안에 제목·기간·총액과 네 항목의 비용으로 배치했습니다. 구분선 중복을 없애고, 넓은 화면은 네 열, 좁은 화면은 두 열로 표시합니다. 금액 입력란은 0일 때 포커스 또는 클릭 시 비워지며, 입력 없이 나오거나 Enter를 누르면 0을 복원합니다. 실제 빈 필수 입력은 미입력 상태를 유지합니다.

인사혁신처 제226호 PDF에서 국내 별지 제3호와 국외 별지 제7호를 확보하고 해당 페이지와 출처를 저장했습니다. 공식 신청서의 항목·병합·서명란을 편집 가능한 Excel·Word 표로 재현하고 앱의 계산 결과는 별첨으로 제공합니다. 공동숙박은 사람별 신청서를 작성하며 동행자에게 운임을 추가하지 않습니다. 알 수 없는 선지급·직급·소속·서명은 추정하지 않습니다. Excel 금액 형식과 합계 캐시를 유지하면서 긴 근거를 별도 시트로 옮기고 Word의 표 너비·테두리·여백·제목 서식을 정리했습니다. 세부 적용 범위는 [출력 서식 안내](출력서식.md)에 기록했습니다.

## 일괄 계산 화면의 출장별 비용 요약

2026-11-18: 전체 예상 출장비 아래에 각 출장의 비용 요약을 자동 표시합니다. 사용자 제공 이미지와 같이 출장명·기간·총액 아래에 일비·식비·숙박비·교통비 금액만 네 칸으로 구분합니다. 날짜별 표·계산식·상태·공동숙박 분담표는 요약 카드에 표시하지 않고 기존 상세 입력·정산 및 출력 문서에서 제공합니다. 별도로 출장을 클릭하거나 입력 중인 출장을 전환하지 않아도 각 출장의 항목별 합계를 볼 수 있습니다.

화면 하단에는 기기 안전영역을 포함한 여백과 스크롤 여유를 두어 마지막 내용 및 저장·다운로드 버튼을 화면 끝에서 충분히 위로 올릴 수 있도록 조정했습니다. 좁은 화면에서도 같은 하단 여백을 유지합니다.

## 공동 출장자의 숙박비만 정산

2026-11-18: 공동 출장자를 추가 출장으로 생성하지 않고 숙박 정산 대상에만 포함하도록 구현했습니다. 국내·근무지 외 간편 입력에 공동숙박 선택과 본인 포함 인원, 선택 입력 이름·개별 등급을 추가했습니다. 영수증 총액을 사람별·날짜별로 분담하고 원 단위 나머지를 보존합니다. 사람별로 독립된 숙박 상한을 적용하므로 타인의 남는 한도를 초과 지출자의 한도로 사용하지 않습니다. 본인 일정과 교통 내역은 한 번만 생성해 동행자의 일비·식비·교통비를 추가하지 않습니다.

거제시 제2호 2명, 3박, 236,634원의 경우 1명당 118,317원·상한 210,000원으로 숙박비 합계 236,634원을 산출합니다. 개별·일괄 Excel·Word에 분담 표를 넣고 저장·JSON에도 사람별 입력과 결과를 보존합니다. 간편 입력은 동일 기간·지역 공동숙박 기준이며 다른 일정·분담액은 상세 숙박 표에서 조정합니다. 국외 공동숙박 및 별도 절감 보상은 범위 밖입니다.

## 화면 구성 개선

2026-11-13 사용자 요청에 따라 화면을 간결하게 정리했습니다.

- 메뉴를 출장 정보·국내 출장·국외 출장·특수 여비·정산서·보관함·지급 기준·설정으로 표시합니다.
- 기본정보를 출장 개요·출장자·일정의 흰색 카드로 묶고, 부서·직위·예외 기준·비고는 펼쳐서 입력하도록 배치했습니다.
- 데스크톱에서는 우측 출장 요약, 좁은 화면에서는 아래쪽 요약을 제공합니다. 초기 입력 화면의 반복 금액 카드는 하나로 통합했습니다.
- 비용 표의 설명은 입력 안내로 옮기고, 상세 항목 토글로 세부 열을 표시합니다. 국내 출장에서는 불필요한 환율 탭을 표시하지 않습니다.
- 정산서에는 총액과 Excel·Word 다운로드를 먼저 보여 주며, 항목별 내역·계산 근거·확인 사항을 탭으로 나눴습니다.
- 계산 엔진과 정산 문서 생성 규칙은 유지했습니다.

## 간편 입력과 Enter 입력 문제 수정

- 8개 메뉴와 단계 이동, 별도 일정 생성 버튼을 제거하고 입력과 결과를 한 화면으로 통합했습니다.
- 기본 입력은 출장 유형·날짜·출장지·숙박/교통 합계이며, 국외는 환율을 추가합니다. 개인 정보·등급·차량·증빙 등은 선택 입력으로 이동했습니다.
- 간편 합계는 기존 계산 엔진의 일정으로 변환합니다. 숙박비는 원 단위로 배분하고 마지막 행에 나머지를 보존하며, 배분 사실도 기록합니다.
- 국내 근무지 외는 사용자가 선택한 ‘다른 시군·왕복 12km 이상’ 구간을 명시적으로 지원합니다. 임의의 숫자 거리를 생성하지 않습니다.
- 예상 출장비와 확정 청구액을 분리했습니다. 예상 환율을 쓰더라도 실제 환율 증빙을 확인한 것으로 저장하지 않습니다. Excel·Word에도 예상액을 추가했습니다.
- Enter 후 값이 사라진 원인은 매 재실행마다 수정된 데이터를 표의 새 원본으로 넘겨 위젯 식별자가 달라지는 구조였습니다. 세션 내 편집 기준 데이터를 고정하고 계산용 Trip만 갱신합니다. 상세 입력 전환·기록 불러오기 때만 기준 데이터를 새로 만듭니다.
- 표 높이를 고정하고 금액·거리·시간에 숫자 열을 사용합니다. 문서번호는 문자열로 보존합니다.

## 자가용 간편 입력 연결

- 교통수단 선택을 추가 옵션에서 기본 화면으로 옮기고 자가용을 추가했습니다.
- 철도·버스 운임 준용과 연료비 방식의 입력을 나누어 기존 자가용 계산 엔진에 연결했습니다. 연료비는 거리·유종·단가·통행료·주차료로 산출하며 선택하지 않은 방식의 기존 입력을 중복 합산하지 않습니다.
- 연료비 계산 방식은 사유 텍스트와 분리하여 저장합니다. 사유·승인·증빙이 아직 없더라도 예상액을 계산하되 확정 지급으로 표시하지 않습니다.
- 동승자 제외와 근무지 내 별도운임 제외를 유지했습니다. 대중교통 운임 미입력은 0원과 구분합니다.
- 상세 교통 표에서도 자가용 계산 항목을 펼쳐 입력할 수 있습니다. 실행 중 열이 추가되었을 때만 편집 기준표를 갱신하며 일반 Enter 입력 시에는 유지합니다.

## 실행 화면 갱신과 상단 제목 여백

- 실제 브라우저에 이전 교통수단 화면이 남아 있는 것을 확인하고 서버를 최신 코드로 다시 실행했습니다. 실행 중 코드 변경이 화면에 반영되도록 Streamlit의 `server.runOnSave`를 켰습니다.

- 오피넷 공개 일별 통계를 조회하여 출발일과 제품이 정확히 일치하는 전국 평균판매가격만 계산에 사용합니다. 별도 API 키나 계정은 필요하지 않습니다.
- 휘발유·경유·LPG 및 하이브리드 연료를 지원합니다. 출발일·유종 변경 시 단가와 출처를 갱신하고, 조회 실패·미발표·날짜 불일치 시 이전 단가를 제거합니다.
- 공개된 평균가의 소수값은 유지하며 단가와 조회 기준일·제품·출처·조회일시를 기록에 보존합니다. 저장 기록의 같은 날짜 조회 자료는 재사용합니다.

## 2026-11-18 · 필수 입력 중심으로 화면 축소

- 기본 화면을 출장 유형, 날짜, 지급 등급, 범위별 필수 입력과 결과 두 영역으로 정리했다. 계산 버튼 없이 입력 즉시 반영한다.
- 당일에는 숙박비·숙박 지역을 표시하지 않고, 근무지 내에는 시간·거리와 필요한 근거리 실비만 표시한다. 국외 국가·도시·환율과 자가용 운임 또는 주행거리·유종·단가 입력은 유지했다.
- 지급 등급은 기본 화면으로 올렸다. 긴 설명은 도움말로 옮기고, 증빙·금액 조정·날짜별 편집·정산 정보·저장·문서 내보내기는 결과 아래 상세 메뉴 하나로 모았다.
- 자가용 통행료·주차료와 유가 직접 입력은 필요할 때만 펼친다. 출발일 기준 오피넷 조회와 기록 보존을 유지했다.
- 숫자 입력의 +/− 버튼, 반복 안내문, 큰 저장 버튼을 기본 화면에서 제거하고 결과를 네 항목의 간결한 합계로 표시했다.
- 필수값이 비어 있으면 필요한 항목 이름과 입력한 항목 합계를 표시한다. 교통수단 없음과 근무지 내 전환 시 기존 교통·숙박비를 잘못 합산하지 않도록 했다.


## 2026-11-18 · 금액 쉼표와 여러 출장의 일괄 계산

- 금액 입력에 천 단위 쉼표를 실시간으로 표시하는 Streamlit v2 구성요소를 추가했다. 커서 위치·소수 부분·빈 입력을 유지하며 Enter/포커스 이동 때 숫자 원문을 계산에 전달한다. 기존 숫자 위젯 상태도 이전한다.
- 출장 추가·전환·묶음에서 제외 기능을 추가했다. 기본 화면은 한 출장씩 편집하고 여러 출장일 때만 전체 합계와 일괄 저장·출력 버튼을 표시한다.
- 각 출장의 적용 법령 자료집, 유가, 환율, 증빙과 상세 표 편집을 보존한다. 기지급액은 출장별로 차감한 뒤 합산한다.
- SQLite에 묶음·묶음 수정 이력 테이블을 추가했다. 묶음과 각 개별 기록을 하나의 트랜잭션으로 저장하며 기존 단일 기록과 수정 이력은 유지한다.
- 일괄 Excel 4개 시트와 전체 요약 및 출장별 상세를 합친 Word를 추가했다. 기존 개별 Excel 9개 시트와 Word 생성은 유지한다. 일괄 문서는 버튼을 누를 때 생성한다.
