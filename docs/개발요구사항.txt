# 개발 요청: 공무원 여비 규정 기반 국내 및 국외 출장비 통합 계산 프로그램

## 1. 프로젝트 목표

대한민국 「공무원 여비 규정」과 인사혁신처의 「공무원보수 등의 업무지침」을 정확하게 적용하여 국내 및 국외 출장비를 계산하고, 모든 입력 내역과 계산 결과를 전문적으로 디자인된 Excel 및 Word 파일로 출력할 수 있는 프로그램을 개발해 주세요.

이 프로그램은 실제 공무 출장비 청구에 사용할 수 있어야 합니다.

**확정된 개발 조건**

- 실행 환경: Python Streamlit 로컬 웹 애플리케이션
- 적용 규정: 대한민국 국가공무원 여비 규정
- 사용 범위: 개인용
- 프로그램 언어: 한국어
- 계산 범위: 국내 출장, 국외 출장, 관련 특수 여비
- 필수 출력: Excel(.xlsx), Word(.docx)
- 사용 방식: 출장 정보를 입력하면 자동 계산하고, 완성된 정산서를 다운로드
- 디자인: 간결하고 현대적이며 전문적인 디자인
- 인터넷 연결: 기본 계산과 파일 생성은 오프라인에서도 가능해야 함

단순한 계산 예제나 프로토타입이 아니라, 모든 기능이 연결되어 실제로 동작하는 프로그램을 구현해 주세요.

## 2. 가장 중요한 개발 원칙

다음 사항을 반드시 지켜 주세요.

1. **계산 정확성이 가장 중요합니다.** 공식 법령 및 업무지침에 따라 계산합니다.
2. 법령 본문뿐 아니라 모든 별표, 별표의 비고, 부칙, 업무지침과 계산 사례까지 검토합니다.
3. 금액을 임의로 설정하지 않으며, 법령의 시행일에 따라 올바른 지급기준을 사용합니다.
4. 법령상 정액, 실비, 상한액, 감액, 추가지급 및 승인 필요 금액을 명확히 구분합니다.
5. 모든 계산 내역에 적용 근거와 계산식을 표시합니다.
6. 입력값을 변경하면 계산 결과가 자동으로 갱신되도록 합니다.
7. 화면에 표시된 금액과 Excel, Word에 출력되는 금액이 반드시 일치해야 합니다.
8. 다운로드되는 Excel 및 Word 파일에는 최종 금액뿐 아니라 **사용자가 입력한 모든 내역과 각 항목의 계산 결과**를 기록합니다.
9. 근거가 확인되지 않거나 승인되지 않은 금액을 확정 지급액으로 표시하지 않습니다.
10. 프로그램 화면과 출력 문서는 모두 일관된 전문적인 디자인을 사용합니다.

불필요하게 복잡한 구조는 피하되, 실제 정산에 필요한 기능을 빠뜨리지 마세요.

확인되지 않은 지급 기준은 추측하지 말고 '근거 확인 필요'로 처리해 주세요.

## 4. 개발 기술

다음 기술을 기본으로 사용해 주세요.

| 기능 | 기술 |
|---|---|
| 웹 인터페이스 | Streamlit |
| 데이터 처리 | Python, pandas |
| 정확한 금액 계산 | decimal.Decimal |
| 출장 내역 저장 | SQLite |
| Excel 생성 및 디자인 | openpyxl |
| Word 생성 및 디자인 | python-docx |
| 날짜 및 시간 처리 | datetime, zoneinfo |
| 계산 규칙 및 기준 데이터 | Python 모듈, JSON 또는 SQLite |
| 테스트 | pytest |

개발 시 다른 라이브러리가 필요하다면 합리적인 이유가 있는 경우에만 추가하세요.

핵심 계산 엔진은 Streamlit UI와 독립적으로 작성합니다.

국내 출장, 국외 출장, 특수 여비, 법령 데이터, 정산 출력 기능은 역할별 모듈로 구분해 주세요.

## 5. 프로그램 사용자 인터페이스

Streamlit 기본 화면을 그대로 나열하는 수준이 아니라, 실제 업무용으로 사용하기 좋은 UI를 제작해 주세요.

### 디자인 방향

- 현대적이고 미니멀한 스타일
- 흰색 또는 매우 연한 회색 배경
- 네이비 계열의 주요 제목
- 절제된 블루 또는 청록색 강조
- 눈에 편한 글꼴과 충분한 여백
- 정돈된 카드, 표, 입력창
- 모든 금액은 세 자리마다 쉼표 표시
- 한국어 날짜 및 통화 형식
- 불필요한 장식과 과도한 색상 사용 금지
- 중요한 최종 청구 금액은 가장 눈에 잘 띄도록 표시
- PC 화면 최적화와 기본적인 모바일 대응

### 기본 화면 구성

사이드바 또는 상단 탐색 메뉴를 사용하여 다음 기능을 제공하세요.

1. 새 출장 등록
2. 국내 출장 계산
3. 국외 출장 계산
4. 특수 여비 계산
5. 계산 결과 및 정산서
6. 저장된 출장 내역
7. 법령 및 지급 기준 안내
8. 프로그램 설정

화면이 복잡해지지 않도록 출장 유형에 맞는 입력 항목만 표시합니다.

다음 정보를 입력할 수 있어야 합니다.

### 출장자

- 성명
- 소속기관
- 부서
- 직위 또는 직급
- 공무원 여부
- 여비 지급등급
- 해당하는 별표 1 세부 구분

### 출장 기본정보

- 출장명
- 출장 목적
- 출장 유형
- 출발지
- 근무지
- 출장지
- 경유지
- 출장 시작 날짜 및 시간
- 출장 종료 날짜 및 시간
- 업무 수행 일정
- 출발 및 복귀 일정
- 출장 승인 여부

여러 장소를 방문할 경우 일정과 장소를 추가하거나 삭제할 수 있도록 구현합니다.

## 7. 국내 출장비 계산

다음 항목을 모두 지원하세요.

### 7.1 근무지 내 및 근무지 외 출장 판정

제18조와 해당 시점의 업무지침을 적용합니다.

- 근무지와 출장지의 행정구역
- 왕복 여행거리
- 12km 기준
- 2km 이내 근거리 출장
- 출장시간 4시간 기준
- 공무용 차량 사용 여부
- 같은 날 여러 차례 출장
- 관련 예외와 감액

2026년 7월 1일 개정과 관련된 행정구역 특례도 반영하세요.

지도 서비스가 없어서 실제 이동거리를 확인할 수 없다면 사용자가 거리를 입력하고 그 출처를 기록하도록 합니다.

### 7.2 국내 일비

- 지급등급별 기본 일비
- 출장일수
- 공무용 차량 이용 시 감액
- 장기체재 감액
- 공적 항공마일리지 관련 추가지급
- 제28조에 따른 조정
- 기타 법정 예외

### 7.3 국내 식비

- 지급등급별 식비
- 인정 출장일수
- 별도 식사 제공
- 행사 또는 다른 기관에서 지급한 식비
- 업무지침상 감액 및 중복 지급 처리
- 항공기 및 선박 이동 중 식비 예외

실제 지급 기준이 없는데 아침, 점심, 저녁을 임의 비율로 나누는 계산은 금지합니다.

### 7.4 국내 숙박비

- 실제 숙박일수
- 각 숙박일의 지역
- 서울, 광역시, 기타 지역 상한
- 지급등급별 기준
- 실제 지출금액
- 숙박비 할인
- 무료 숙박
- 주최기관 숙박비 지원
- 기준 초과금액
- 불가피한 초과지출 인정
- 승인 및 증빙 여부
- 정산 기한

여러 지역에서 각각 숙박했다면 1박씩 다른 지역 상한을 적용합니다.

### 7.5 국내 교통비

- 철도
- 고속버스 및 시외버스
- 항공기
- 선박
- 자가용
- 공무용 차량
- 기타 법령상 인정되는 교통비

좌석등급, 이동 구간, 실제 운임, 할인, 무료 교통수단, 기관의 직접 지급 여부를 처리합니다.

자가용의 연료비, 통행료, 주차비 등은 관련 업무지침에서 지급을 허용하는 범위만 반영합니다.

## 8. 국외 출장비 계산

모든 국가 및 도시의 법정 여비 지급 기준을 지원해야 합니다.

### 8.1 국가와 도시 선택

- 국가 검색
- 도시 검색
- 별표 4의 가, 나, 다, 라등급 자동 적용
- 국가 내 도시별 예외
- 지급등급별 금액 조회
- 국가와 도시를 여러 개 추가할 수 있는 기능
- 날짜별 체류지 지정

도시별 기준을 정확히 찾을 수 없는 경우 별표의 일반 규칙을 확인하고, 불명확하면 사용자 검토 대상으로 표시합니다.

### 8.2 국외 일비

- 지급등급
- 국가 및 도시 등급
- 인정 출장일수
- 국가 간 이동일
- 출국일 및 귀국일
- 장기체재
- 법정 감액
- 기타 특수 조건

### 8.3 국외 식비

- 국가 및 도시 등급별 지급액
- 날짜별 지급 기준
- 식사 제공 여부
- 항공기 및 선박 이동 중 식사
- 행사 주최기관의 지원
- 중복 지원
- 지급액 조정
- 인정되는 초과지급

### 8.4 국외 숙박비

- 숙박 날짜
- 숙박 국가와 도시
- 지급등급
- 숙박비 상한
- 실제 결제 금액
- 외화 통화
- 초과지출 여부
- 추가지급 승인
- 증빙 여부
- 무료 숙박 및 기관 부담 금액

### 8.5 국외 교통비

- 국제 항공운임
- 국내 연결 항공운임
- 국외 현지 항공편
- 국외 철도 및 버스
- 선박
- 기타 인정 운임
- 좌석등급
- 할인 및 마일리지
- 기관 직접 결제

별표 3에 따라 지급 가능한 좌석등급을 확인하세요.

### 8.6 국외 출장 준비금

법령에서 인정하는 준비금 항목을 지원합니다.

비자, 예방접종, 보험 등은 해당 규정에서 허용하는 항목만 지급 가능 금액에 포함합니다.

### 8.7 환율

- 통화별 실제 지출액
- 공식 적용 환율
- 환율 기준일
- 환율 정보 출처
- 외화 합계
- 원화 환산금액
- 환산 및 반올림 기준

여러 통화로 결제했더라도 항목별 환율을 적용하여 최종 원화 금액을 계산합니다.

가능하다면 공식 환율 자료를 조회하고, 오프라인에서는 수동 입력이 가능하도록 합니다.

임의의 환율을 실제 환율처럼 사용하지 마세요.

## 10. 자동 계산 기능

**사용자가 필요한 값을 입력하면 별도의 복잡한 절차 없이 자동으로 계산되어야 합니다.**

### 계산 동작

1. 필수 항목을 입력합니다.
2. 입력값의 형식과 논리적 일관성을 검증합니다.
3. 적용 법령과 지급등급을 확인합니다.
4. 국내 또는 국외 출장 기준을 적용합니다.
5. 출장일수와 숙박일수를 계산합니다.
6. 교통비, 일비, 식비, 숙박비 등을 계산합니다.
7. 감액 및 예외지급 기준을 적용합니다.
8. 지원받은 금액과 이미 지급된 금액을 구분합니다.
9. 최종 청구 가능 금액을 표시합니다.
10. 입력값이 변경되면 결과와 출력용 데이터가 갱신됩니다.

### 계산 결과 표시

최상단에 큰 글씨로 다음 정보를 보여주세요.

**최종 청구 가능액: 000,000원**

그 아래에는 다음을 표시합니다.

| 항목 | 기준금액 | 실제 지출액 | 인정금액 | 최종 청구액 |
|---|---:|---:|---:|---:|
| 일비 | 자동 | 해당 없음 | 자동 | 자동 |
| 식비 | 자동 | 입력값 | 자동 | 자동 |
| 숙박비 | 자동 | 입력값 | 자동 | 자동 |
| 교통비 | 기준에 따름 | 입력값 | 자동 | 자동 |
| 기타 인정 여비 | 기준에 따름 | 입력값 | 자동 | 자동 |
| 합계 | | | | 자동 |

실제 지출액이 필요한 경우와 정액으로 계산하는 경우를 구분하세요.

모든 계산 항목을 펼치면 다음 내용을 확인할 수 있도록 합니다.

- 적용 기준금액
- 인정 수량 또는 날짜
- 계산식
- 감액 사유
- 추가 인정 금액
- 적용 법령
- 증빙 필요 여부
- 승인 필요 여부

미입력 필수정보, 증빙 부족, 법적 판단이 필요한 항목은 확정 금액과 분리하여 표시합니다.

# 11. Excel 파일 출력

**Excel 파일의 디자인과 실용성은 프로그램의 핵심 기능입니다.**

openpyxl을 사용하여 전문적인 출장비 정산 Excel 문서를 생성하세요.

단순히 pandas DataFrame을 Excel로 저장하는 방식은 허용하지 않습니다.

## 11.1 Excel 파일 구성

다음 시트를 기본으로 생성하세요.

| 시트 | 내용 |
|---|---|
| 01_출장비_요약 | 출장 기본정보, 항목별 합계, 최종 청구액 |
| 02_출장_기본정보 | 사용자가 입력한 출장자, 출장 목적, 장소, 일정 등 모든 기본정보 |
| 03_상세_일정 | 날짜별 이동, 방문 국가 및 도시, 업무 수행 및 숙박 정보 |
| 04_교통비_내역 | 모든 교통수단과 구간별 실제 지출액 및 인정액 |
| 05_숙박비_내역 | 각 숙박일의 실제 지출액, 상한액, 지급액 및 감액 |
| 06_일비_식비 | 날짜별 적용 기준, 계산식, 인정액 및 감액 |
| 07_기타_경비 | 준비금, 이전비, 가족여비 등 해당되는 비용 |
| 08_계산_근거 | 계산 항목별 적용 법령, 별표, 계산식 및 출처 |
| 09_정산_검토 | 증빙자료, 승인 필요 항목, 부족한 정보 및 특이사항 |

출장에 없는 항목은 해당 시트를 생략하거나 '해당 없음'으로 명확히 처리합니다.

국외 출장에서는 통화별 지출액, 적용 환율, 원화 환산액을 모두 표시합니다.

## 11.2 Excel 디자인 요구사항

전체적으로 **깔끔한 행정 문서와 현대적인 재무 보고서의 장점을 결합한 디자인**을 적용하세요.

### 스타일

- 흰색 배경
- 주요 제목은 네이비
- 주요 합계와 강조 항목은 블루 또는 청록색
- 표 헤더는 절제된 단색 배경
- 일반 행에는 흰색과 매우 연한 회색을 활용
- 장식적인 그래프와 과도한 강조색은 사용하지 않음
- 모든 시트에 통일된 서식 적용

### 세부 서식

- 한글이 정상 표시되는 글꼴 사용
- 제목, 소제목, 본문의 크기를 명확히 구분
- 숫자에는 세 자리 쉼표 적용
- 원화는 `#,##0"원"` 등의 표시 형식 사용
- 외화는 통화별 적절한 형식 사용
- 금액은 오른쪽 정렬
- 텍스트는 왼쪽 정렬
- 날짜는 통일된 형식
- 필요할 때 셀 병합
- 자동 줄바꿈
- 열 너비와 행 높이 최적화
- 가독성이 좋은 테두리
- 표 헤더 고정
- 적절한 자동 필터 적용
- 합계 행 강조
- 오류 또는 승인 필요 항목만 제한적으로 조건부 서식 사용

### 인쇄 설정

- A4 용지 기준
- 기본적으로 가로 또는 세로 방향 자동 최적화
- 인쇄영역 설정
- 반복 헤더 설정
- 페이지 여백 최적화
- 불필요한 빈 페이지 방지
- 표가 잘리지 않도록 페이지 배율 설정

## 11.3 Excel 계산 데이터

Excel 문서에는 입력값과 계산 결과를 모두 남겨야 합니다.

가능한 항목에서는 Excel 수식을 사용하되, 프로그램에서 계산된 원래 값과 불일치하지 않게 구현하세요.

법령에 따른 복잡한 계산을 Excel 수식으로 안전하게 재현할 수 없다면 다음을 기록합니다.

- 계산 입력값
- 계산식 설명
- 프로그램에서 계산한 확정 금액
- 해당 법령 근거
- 적용 규칙의 버전

단순 합계와 소계는 Excel 수식으로 연결할 수 있습니다.

Excel을 열었을 때 최종 금액이 표시되어야 하며, 수식 계산 캐시가 없는 환경에서 금액이 비어 보이는 문제가 발생하지 않도록 처리하세요.

## 11.4 Excel 사용성

- 시트를 열면 가장 먼저 요약 시트가 보이도록 설정
- 요약 시트의 최종 청구액이 가장 눈에 띄도록 구성
- 원본 입력값과 계산된 금액을 명확히 구분
- 법령 출처는 클릭 가능한 링크로 제공
- 열 너비가 지나치게 좁거나 넓지 않도록 조정
- 내용이 길면 셀 내부에서 정상적으로 표시
- 빈 값, 0원, 해당 없음 구분
- 저장 후 Microsoft Excel에서 정상적으로 열리는 구조

# 12. Word 파일 출력

**Word 파일은 실제 출장비 청구서로 제출할 수 있을 만큼 전문적이고 깔끔하게 디자인해 주세요.**

python-docx를 사용하여 완전한 DOCX 문서를 생성하세요.

단순히 텍스트와 표를 나열한 문서가 아니라, 정식 행정 정산서 형태의 결과물을 만들어야 합니다.

## 12.1 Word 문서 구성

### 표지 또는 첫 페이지 상단

문서 제목:

**국내 출장비 정산서**

또는

**국외 출장비 정산서**

문서 상단에 다음 정보를 정돈된 형태로 표시합니다.

- 출장명
- 출장자
- 소속
- 직급 및 지급등급
- 출장 기간
- 출장 국가 및 지역
- 출장 목적
- 적용 여비 규정

불필요하게 큰 표지는 만들지 않고 첫 페이지부터 핵심 정보가 보이도록 구성합니다.

### 1. 출장 개요

사용자가 입력한 기본정보를 표로 표시합니다.

### 2. 출장 일정

일자별 이동 및 업무 일정을 정리합니다.

### 3. 출장비 정산 총괄

가장 중요한 표입니다.

| 항목 | 계산 기준 | 인정 금액 |
|---|---|---:|
| 교통비 | 실제 인정 운임 | 자동 |
| 일비 | 지급 기준 × 인정일수 | 자동 |
| 식비 | 지급 기준 × 인정일수 | 자동 |
| 숙박비 | 실제 지출액 및 상한 | 자동 |
| 기타 여비 | 법정 인정 항목 | 자동 |
| **최종 청구액** | | **자동** |

최종 청구액은 문서 내에서 명확하게 강조하세요.

### 4. 항목별 상세 계산

모든 교통비, 일비, 식비, 숙박비 및 기타 여비의 세부 내역을 기록합니다.

국외 출장이라면 날짜별 국가 및 도시, 현지 통화, 적용 환율 및 원화 환산액을 표시합니다.

### 5. 지급 조정 및 예외

- 감액 내역
- 초과지출
- 추가지급 승인
- 기관 부담 비용
- 중복 지원
- 기타 정산 조정

### 6. 증빙 및 정산 확인

- 필요한 증빙자료
- 입력한 증빙자료 목록
- 부족한 증빙
- 승인 필요 항목
- 정산 기한
- 참고사항

### 7. 적용 법령 및 계산 근거

실제로 사용한 법령의 시행일, 조문, 별표, 업무지침 및 링크를 정리합니다.

법령 문장 전체를 불필요하게 복사하지 않고 실제 계산에 사용된 근거를 기록하세요.

## 12.2 Word 디자인 요구사항

### 기본 스타일

- A4 세로
- 흰색 배경
- 네이비 제목
- 검정 또는 진한 회색 본문
- 제한적인 블루 계열 강조
- 통일된 한글 글꼴
- 깔끔한 표 디자인
- 충분한 문단 및 표 간격
- 불필요한 장식과 색상 사용 금지

### 제목 및 본문

- 문서 제목: 약 18~20pt
- 주요 섹션 제목: 약 12~14pt
- 본문: 약 9~11pt
- 표 내부 글씨: 약 9pt

실제 내용에 따라 적절하게 조정합니다.

### 표

- 표 헤더에 연한 색상 배경 적용
- 주요 금액은 굵게 표시
- 숫자 오른쪽 정렬
- 내용에 따른 적절한 셀 너비
- 세로 정렬 통일
- 일정한 셀 내부 여백
- 페이지가 바뀔 때 표 헤더 반복
- 한 행이 페이지 사이에서 부자연스럽게 잘리지 않도록 처리
- 총액 행은 명확히 강조

### 페이지 구성

- 머리글에 문서명 또는 출장명 표시
- 바닥글에 페이지 번호 표시
- 적절한 페이지 여백
- 불필요한 빈 페이지 방지
- 내용에 따라 자연스러운 페이지 나누기
- 짧은 출장에서는 과도하게 많은 페이지를 만들지 않음
- 긴 출장에서도 표가 잘리거나 문장이 겹치지 않음

### Word 문서 편집성

- 모든 표와 텍스트는 Word에서 직접 수정 가능해야 함
- 전체 문서를 이미지로 변환하는 방식 금지
- 별도의 유료 서체를 요구하지 않음
- 한글이 깨지지 않도록 동아시아 글꼴 설정
- Microsoft Word에서 정상적으로 열리는 DOCX 사용

## 13. 프로그램과 출력 문서 디자인 통일

Streamlit 화면, Excel, Word는 서로 다른 프로그램처럼 보이지 않아야 합니다.

하나의 공통 디자인 시스템을 사용하세요.

### 디자인 테마

- Primary: 차분한 네이비
- Accent: 절제된 블루 또는 청록색
- Background: 흰색
- Secondary Background: 매우 연한 회색
- Text: 진한 회색
- Border: 연한 회색

### 공통 구성

- 통일된 제목
- 통일된 항목명
- 통일된 금액 표현
- 통일된 계산 결과 순서
- 일관된 소계 및 합계 강조
- 동일한 최종 청구액
- 일관된 법령 근거 표시

Excel과 Word의 금액, 일정, 지급등급, 적용 규정이 서로 다른 일이 발생하지 않아야 합니다.

시각적 완성도뿐 아니라 실제 출력과 읽기 편의성을 우선하세요.

## 14. 파일 다운로드 및 저장 기능

출장비 계산을 마치면 결과 화면에서 다음 버튼을 제공합니다.

**Excel 정산서 다운로드 (.xlsx)**

**Word 정산서 다운로드 (.docx)**

두 버튼은 항상 동일한 확정 계산 결과를 바탕으로 파일을 생성해야 합니다.

파일명은 예를 들어 다음과 같이 자동 생성합니다.

- `국내출장_출장비정산서_20261113.xlsx`
- `국내출장_출장비정산서_20261113.docx`
- `국외출장_출장비정산서_20261113.xlsx`
- `국외출장_출장비정산서_20261113.docx`

동일한 날짜에 여러 출장이 있는 경우 파일명이 충돌하지 않도록 출장명 또는 식별자를 사용할 수 있습니다.

### 다운로드 파일에 반드시 포함할 정보

1. 사용자가 입력한 모든 출장 기본정보
2. 출장자 정보 및 지급등급
3. 출장 시작 및 종료 일정
4. 일자별 출장 장소
5. 교통수단별 이동 내역

7. 날짜별 일비 계산
8. 날짜별 식비 계산
9. 숙박일별 숙박비 계산
10. 기타 여비 및 준비금
11. 감액 및 추가지급 내역
12. 다른 기관이 지원한 금액
13. 통화 및 적용 환율
14. 항목별 소계
15. 전체 합계
16. 최종 청구 가능 금액
17. 계산에 적용한 법령 및 별표

23. 프로그램이 적용한 법령 데이터 버전

입력값 중 하나라도 의미 있는 값이 누락되지 않도록 공통 데이터 모델을 사용합니다.

Word에서 너무 긴 내역은 적절한 부록으로 구성해도 좋지만, 내역 자체를 생략해서는 안 됩니다.

### 저장 및 불러오기

SQLite를 사용해 개인 출장 기록을 저장합니다.

- 새 출장 등록
- 기존 출장 불러오기
- 수정
- 재계산
- 복사하여 새 출장 생성
- 삭제
- 정산서 재생성

과거 계산 기록은 당시 사용한 법령과 환율 정보를 유지합니다.

다시 계산할 때는 원래 기준으로 계산할지, 새로운 법령 기준으로 재계산할지 명확히 선택할 수 있도록 합니다.

별도의 회원가입이나 로그인은 필요하지 않습니다.

## 15. 계산 정확성 및 예외 처리

다음 원칙을 준수하세요.

### 금액 계산

- 부동소수점 오차를 방지하기 위해 Decimal 사용
- 법령 및 업무지침에 따른 반올림 또는 절사
- 환율 적용 시점과 방법 명시
- 날짜 경계와 시간대 처리
- 국가 간 이동일 처리
- 날짜별 요금 차이 반영
- 숙박하지 않은 날짜의 숙박비 제외
- 실제 지출액과 법정 인정액 구분
- 지급기관이 직접 부담한 비용 구분
- 승인되지 않은 추가지급액 제외

### 상태 관리

모든 계산 항목은 아래 중 적절한 상태를 가져야 합니다.

- 계산 확정
- 증빙 필요
- 승인 필요
- 근거 확인 필요
- 지급 제외

이 상태는 화면과 Excel, Word 모두에 표시합니다.

필수정보가 없으면 무조건 0원으로 계산하지 말고, 정보 미입력 상태와 실제 0원을 구분합니다.

### 법령 충돌 및 불확실성

관련 규정이 여러 개일 경우 적용 우선순위를 확인합니다.

기준이 명확하지 않다면 법령을 임의로 해석하지 않고 해당 항목을 검토 대상으로 표시합니다.

국가공무원 여비 규정에 없는 기관별 자체 지급기준은 임의로 추가하지 않습니다.
