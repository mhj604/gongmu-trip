# 출장비 계산기 사용법

## 바로 계산하기

1. 국내 또는 국외를 선택하고 출발일·복귀일을 입력합니다.
2. 국내는 숙박 지역과 근무지 내·외를 선택합니다. 국외는 국가·도시와 원화 환율을 입력합니다.
3. 숙박비와 왕복 교통비를 **출장 전체 합계**로 입력하면 아래 예상 출장비가 바로 바뀝니다. 당일 출장은 숙박비를 입력하지 않습니다.

이름·소속·출장명·목적은 계산을 시작하는 데 필요하지 않습니다. 정산서에 넣을 때만 `정산서 정보 · 선택 입력`을 펼쳐 작성하세요.

지급등급은 제2호가 기본입니다. 등급 변경·공무용 차량·교통수단·기지급액은 `추가 옵션`에 있습니다. 공무용 차량 체크는 일비 감액에 적용합니다. 기관이 운임을 직접 결제했다면 개인 교통비에는 그 금액을 넣지 마세요.

## 입력 기준

- **근무지 외**: 다른 시·군이고 왕복 12km 이상인 출장입니다. 정확한 거리를 임의로 만들지 않고 사용자가 선택한 구간으로 판정합니다.
- **근무지 내**: 같은 시·군이거나 왕복 12km 미만인 출장입니다. 하루 출장시간과 왕복거리를 입력합니다. 왕복 2km 이내에는 하루 실제 교통비·식비가 추가로 필요합니다.
- **국내 출장지**: 서울·광역시·기타 중 숙박비 상한이 적용되는 지역을 고릅니다.
- **숙박비 합계**: 같은 지역·같은 숙박 조건으로 계산합니다. 계산을 위해 원 단위로 각 숙박일에 균등 배분하고 나머지는 마지막 날에 더합니다. 배분 사실을 원본 입력과 정산서에도 기록하며, 날짜별 실제 지출로 표시하지 않습니다.
- **국외 금액**: 간편 입력의 숙박·교통비는 원화 결제액입니다. 직접 입력한 USD 환율은 예상 계산에만 쓰며 실제 환전 증빙을 확인한 것으로 저장하지 않습니다.
- **예상 출장비**: 입력 조건으로 산출 가능한 미확정 금액도 포함합니다. 금액 자체를 산출할 수 없는 항목은 합계에 포함하지 않고 안내합니다. 승인·증빙이 반영된 확정 청구액과 구분합니다.
- **기지급액**: 예상 출장비 자체를 바꾸지 않고 차감 후 예상액을 별도로 표시합니다.

간편 입력은 모든 날짜를 여비 인정일, 출발 다음 날부터 같은 출장지에 계속 체재한 일정, 같은 지역에서의 숙박으로 구성합니다. 개인 일정·타지역 이동·무료 식사·일부 날짜 숙박 등이 있으면 날짜별 입력을 사용하세요.

## 날짜마다 조건이 다를 때

`날짜별로 다르게 입력`을 켜면 일정·숙박·교통·증빙 표가 나타납니다. 국외는 환율 표도 표시됩니다. 간편 입력에서 만든 일정과 금액을 출발점으로 수정할 수 있습니다.

각 표에 값을 넣고 **Enter**를 누르면 바로 반영됩니다. 다른 셀을 수정하거나 다른 입력을 변경해도 편집 중인 값과 표의 높이를 유지합니다. 행 추가·삭제, 0원과 미입력을 구분하여 보존합니다. 문서번호는 숫자처럼 보여도 문자열로 보존합니다.

여러 지역에 숙박했다면 각 숙박일의 지역·실제 금액을 수정하세요. 무료 제공·기관 결제는 해당 행에 표시합니다. 국외 카드 상세 정산은 카드청구 원화액·현지 환율 기준일·출처를 입력합니다. 기존 저장 기록의 숨겨진 상세 항목과 추가 여비도 보존됩니다.

상세 입력을 끄면 표 대신 간편 입력 합계로 일정을 다시 구성합니다. 기존 기록을 불러올 때는 상세 입력을 기본으로 열어 기존 내역을 합계 입력으로 덮어쓰지 않습니다.

## 저장과 다운로드

- `계산 저장`으로 현재 입력과 결과, 적용 법령 자료를 이 기기에 저장합니다.
- 오른쪽 위 `내 기록`에서 저장된 계산을 불러오거나 새 계산을 시작합니다. 불러온 기록은 저장 당시 법령 자료집을 사용합니다.
- `계산 내역 · Excel / Word 다운로드`를 펼치면 항목별 금액·산식·미확정 사유와 문서 다운로드가 있습니다.
- Excel·Word에는 화면과 같은 예상 출장비를 표시하고 확정 청구액을 별도로 기록합니다. 입력한 이름·소속 등이 없으면 확정 청구에 필요한 정보 부족 사유도 남습니다.
- JSON 입력 백업도 내려받을 수 있습니다. 실제 영수증 파일은 올리지 않고 증빙 표에 문서번호와 보관 위치를 기록합니다.

법령 자료와 계산의 지원 범위는 [법령과 계산 기준](법령과계산기준.md), [지원 범위](지원범위.md)를 참고하세요.

## 자가용으로 출장할 때

간편 화면의 **교통수단 → 자가용**을 선택합니다. 자가용 입력은 `추가 옵션`을 열지 않아도 표시됩니다.

- **대중교통 운임**: 같은 구간의 철도·버스 왕복 운임을 입력합니다. 자가용을 이용했다는 이유만으로 연료비를 자동 가산하지 않습니다.
- **연료비**: 왕복 총 주행거리, 유종, 연료 단가를 입력하고 통행료·주차료가 있으면 더합니다. `주행거리 × 연료 단가 ÷ 기준 연비 + 통행료 + 주차료`로 예상 교통비를 계산합니다. 기존 왕복 교통비 입력과 중복 합산하지 않습니다.

전기는 원/kWh, 수소는 원/kg, 나머지는 원/L로 단가를 입력합니다. 유가·충전요금은 자동으로 가정하거나 가져오지 않습니다. 거리에는 왕복 및 인정되는 경유 구간의 총거리를 한 번만 입력하세요.

예를 들어 휘발유 기준 연비 11.97km/L에 주행거리 119.7km, 단가 1,700원/L, 통행료 5,000원, 주차료 3,000원을 입력하면 교통비는 **25,000원**입니다. 이는 계산 예시이며 실제 유가가 아닙니다.

`자가용 증빙·승인 정보 · 선택 입력`에서 운임 출처, 거리·단가 출처, 부득이한 사용 사유와 승인 근거를 기록할 수 있습니다. 미입력 상태에서도 산출 가능한 예상액은 표시하고 확정 청구액은 구분합니다. 동승자는 체크하면 자가용 운임에서 제외됩니다.

근무지 내 출장은 시간·거리 기준의 여비를 적용하며 연료비를 별도로 더하지 않습니다. 날짜별 입력의 교통 탭에서는 `자가용 입력란 표시`를 켜면 같은 계산 항목을 편집할 수 있습니다. 기존에 자가용이 입력된 기록은 해당 입력란이 기본으로 표시됩니다.

일반 자가용 출장의 철도·버스 운임 기준과 부득이한 경우의 연료비 정산은 [공무원 여비 규정](https://www.law.go.kr/법령/공무원여비규정) 별표 2 비고 및 [인사혁신처 여비 안내](https://www.mpm.go.kr/mpm/info/resultPay/resultPayIntro/)를 따릅니다.
