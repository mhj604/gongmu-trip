# 바른여비 사용 설명서

## 출장 기본정보

성명·소속기관·출장명·목적·기간·지급등급을 입력합니다. 일시는 한국시간으로 저장합니다. 국외 현지 시간대와 출발·복귀 일정은 별도 입력란에 남깁니다. 국제 날짜변경선으로 지급 인정일이 달라지면 일별 일정에 추가하고 날짜변경선 근거를 입력합니다. 현지 시각만으로 인정일을 자동 결정하지 않습니다.

지급등급은 별표 1의 원문을 보고 선택합니다. `제1호가/나/다/라`, `제2호`를 구분합니다. 대통령·국무총리의 일비·식비 실비는 별도 근거 확인 상태입니다. 비공무원은 별표 9 구분과 준용·기관결정 근거를 입력해야 합니다. 공공기관 임원·직원은 각각 제1호라·제2호를 적용하는 버튼이 있습니다.

## 일별 일정

일정 자동 생성은 기존 일정과 숙박 행을 대체합니다. 장소를 바꿀 수 있고 표의 마지막 행에서 추가하거나 선택한 행을 삭제할 수 있습니다. `세부 입력 열 모두 보기`를 선택하면 모든 조건을 수정할 수 있습니다.

국내는 동일행정구역 여부, 왕복거리와 출처, 출장시간을 입력합니다. 거리 12km **미만**이 근무지 내 기준입니다. 12km 이상이라도 같은 시군이면 원칙적으로 근무지 내입니다. 도서·교량, 타 시군 경유 등 기관 판정 예외는 세부 열의 조건과 승인 근거를 입력합니다.

통합특별시 해당 시 종전 근무지 시군과 각 일정의 종전 출장지 시군을 입력합니다. 숙박 상한은 종전 광주광역시 지역이면 광역시, 종전 전남 시군이면 기타를 선택합니다.

같은 날 여러 근무지 내 출장은 시간과 근거리 실비를 한 행으로 합산합니다. 하루 20,000원 한도를 적용합니다. 왕복 2km 이내는 4시간 미만 운임 실비, 4시간 이상 운임과 식비 1/3 범위의 실비를 적용합니다. 증빙을 표시해야 확정됩니다.

장기체재는 `도착다음날기산일수`를 수정합니다. 도착일과 출발일은 0, 도착 다음 날은 1입니다. 같은 곳 체재 중 임시 타지역 출장일은 기산일에서 제외합니다. 자동 생성값은 단순 연속 체재 가정이므로 이동 일정에 맞춰 수정해야 합니다.

별도 식사 제공은 세부 열의 `숙식제공여부`를 선택하고 `식비조정액`, `식비조정근거`를 입력합니다. 법적 기준이 확인되지 않은 일률적인 아침·점심·저녁 1/3 감액은 하지 않습니다. 조정할 금액이 없다면 근거와 함께 `0`을 입력합니다. 항공·선박 이동 중 별도 식비가 필요하면 `별도식비필요`를 선택합니다.

국외는 각 날짜의 **지급기준 국가·도시**를 입력합니다. 이동일에 여러 국가가 있으면 해당 여행 경로에 따라 적용할 국가를 지정합니다. 프로그램은 항공편을 조회하여 이동일 국가를 자동 추론하지 않습니다. 미열거 국가는 가장 가까운 열거 국가의 수도와 거리 근거를 입력합니다. 홍콩은 국가 중국·도시 홍콩으로 입력할 수 있습니다.

## 숙박비

실제 1박당 1행을 작성합니다. 숙박일, 도시, 실제 지출액, 통화, 증빙을 입력합니다. 지역별 상한을 합산한 뒤 출장 전체 순지출과 비교하므로, 경주 67,000원·부산 82,000원의 예시는 149,000원을 인정합니다. 날짜별로 70,000원·80,000원 상한에 각각 잘라 합산하지 않습니다.

무료 또는 기관 직접결제는 해당 열에 표시합니다. 할인 전 금액을 실제 지출액에 입력했다면 할인액을 따로 입력하고, 할인 후 결제액을 입력했다면 할인액은 비워 둡니다. 지원액·기관부담액도 해당 통화 단위로 입력합니다.

국외 카드 숙박은 신청 당시의 `1USD당현지통화`, 환율 출처·기준일, 수수료가 포함된 `카드청구원화액`을 입력합니다. 현지 통화 결제액이 USD 상한 이내면 카드사의 원화 청구액을 지급하고, 초과하면 원화 상한과 청구액 중 작은 금액을 적용합니다. 십원 미만을 절사합니다. 여러 국가의 숙박도 같은 출장 정산풀로 비교합니다.

국내에서 원화 예약한 국외 숙박은 통화를 KRW로, 결제수단을 국내원화예약으로 입력합니다. 현금은 영수증과 카드 사용 불가 등의 사유를 입력합니다. 기관카드 결제는 개인 청구가 없으므로 기관직접결제를 선택합니다. 기관카드 국고 반납 절차 자체를 자동 처리하지는 않습니다.

불가피한 초과지출은 세부 열에서 `초과신청`을 선택합니다. 추가금은 국내 30%, 국외 50%의 법정 한도 안에서 분리합니다. 증빙과 승인·승인근거가 있어야 확정액에 포함합니다. 동행 등급 조정과 초과지급을 동시에 선택하면 근거 확인 대상으로 남깁니다.

국외 할인정액은 출장 전체에 적용하는 옵션입니다. 승인과 근거를 입력하고 숙박일·국가·도시를 기록합니다. 실제숙박이 없거나 무료 숙박인 날은 제외합니다. 일반 실비와 부분 혼합하는 방식은 지원하지 않습니다.

## 교통비

운임은 구간별로 입력합니다. 실제 지출액, 할인·지원·기관부담을 구분합니다. 국내 제2호 특실이나 법정 기준을 넘는 항공 좌석은 확정하지 않습니다. 일반 좌석 외 예외는 승인만으로 확정하지 않고 법정 대상과 집행지침을 추가 확인하도록 표시합니다.

자가용의 일반 지급은 해당 구간 철도·버스 운임과 출처가 필요합니다. 부득이한 자가용 사용은 사유·승인·거리·유가와 각 출처, 영수증을 입력합니다. 법정 연비로 연료비를 계산하며 통행료·주차료를 더합니다. 동승자는 운임을 지급하지 않습니다. 전기·수소·하이브리드·플러그인하이브리드의 연비·전비 구분을 지원합니다.

국외 통화별 비용에는 환율ID를 선택적으로 입력할 수 있습니다. 카드사의 확정 환율이 출장 복귀 뒤에 나온 경우에도 해당 ID를 지정하면 그 환율을 사용합니다. 현지 시내 택시처럼 일비와 중복될 수 있는 비용은 별도 근거 확인 상태입니다.

## 특수 여비

입력 항목 안내에서 종류를 고르면 관련 열을 표시합니다. 여러 종류를 한 출장에 추가할 수 있습니다.

- 이전비: 기본구간 실비와 법정 상한까지의 초과구간 실비를 분리합니다. 단순 중량 비례로 전체 이사비를 임의 배분하지 않습니다. 발령일·이전일·이전 요건 확인과 증빙·승인을 기록합니다.
- 가족여비: 해당 가족의 구간에 대한 본인 등급 기준 산출액을 운임·숙박·일비식비·준비금으로 구분합니다. 나이·관계·독립생계·예외 확인과 가족 동반·허가 요건을 입력합니다.
- 상시출장: 법령이 전국 공통 월액을 정하지 않으므로 기관에서 확정한 금액과 지급기준이 필요합니다.
- 준비금: 비자·예방접종·보험·풍토병 예방약·출입국 필수 법정감염병 검사만 지원합니다. 여권 발급비 등은 임의 포함하지 않습니다.
- 국내 사망자 여비: 법정 해당구간의 전직 상당 여비와 산출근거를 입력하고 유족 지급 승인을 기록합니다.
- 퇴직·휴직·사무인계·국외 사망자·기타 특례: 구간·가족·기한 등 자동 요건 판정이 구현되지 않아 미확정 내역으로 보존합니다.

## 결과와 저장

청구액은 확정 인정액에서 기지급액을 한 번 차감한 금액입니다. 기지급액이 더 크면 반납예정액을 별도 표시합니다. 확정되지 않은 항목이 있으면 화면과 문서 제목은 `현재 확정 항목 청구액`으로 바뀝니다. 산정 자체가 불가능한 금액은 `미입력`으로 표시하며, 미확정 합계 숫자만으로 누락 여부를 판단하지 않습니다.

저장 당시 결과와 법령 자료집은 SQLite에 보존합니다. 불러온 후 설정에서 저장 당시 자료집 사용을 선택할 수 있습니다. `지정일 기준 재계산`은 개정 영향 비교용이며 실제 과거 청구 기준을 바꾸는 기능이 아닙니다. 저장 내역 화면의 다운로드는 저장 당시 결과를 재생성합니다.

JSON 백업은 원본 입력·결과·자료집을 포함하며, SQLite 백업은 모든 개인 기록을 포함합니다. 자료를 다른 기기에 옮긴 뒤 설정 화면에서 JSON을 가져올 수 있습니다.
