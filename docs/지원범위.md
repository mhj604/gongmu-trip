# 지원 범위와 남은 항목

`근거 확인 필요` 항목은 입력값을 보존하고 출력 문서에도 남기지만, 확정 청구액에 합산하지 않습니다. 법령 원문을 확보한 항목이라도 기관 결정이나 자동 판정이 구현되지 않은 조건이 남으면 같은 상태를 사용할 수 있습니다.

따라서 이 배포본은 **기능이 연결되어 실행되는 앱**이지만 요청서의 모든 특수 사례에 대한 완전 자동 정산 완료본은 아닙니다. 특히 위 표의 미구현 항목에 의존하는 실제 청구를 완성된 자동 산정으로 설명해서는 안 됩니다.
