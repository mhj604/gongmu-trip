# 바른여비

국가공무원의 국내·국외 출장비를 계산하고 **Excel 9개 시트와 편집 가능한 Word 정산서**를 만드는 개인용 Streamlit 앱입니다. 입력 변경 시 재계산하며, 입력·계산 결과·환율·법령 자료집을 SQLite에 함께 저장합니다.

**자동 계산이 가능한 항목과 기관 판단이 남는 항목을 구분한 첫 배포본입니다. 모든 법정 특례의 자동 판정까지 완료한 제품은 아닙니다.** 퇴직·휴직·국외 사망자 여비, 기관별 특례협의, 과거 자료가 없는 기간 등은 `근거 확인 필요`로 표시합니다. [지원 범위](docs/지원범위.md)에 세부 상태를 공개합니다.

## 실행

Python **3.12 이상**을 설치한 뒤 저장소 폴더에서 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell은 활성화 명령 대신 아래처럼 실행할 수 있습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 [로컬 앱](http://localhost:8501)을 엽니다. 의존성 설치 후에는 **기본 계산·저장·문서 생성에 인터넷이 필요하지 않습니다.** 법령 원문 링크 열기와 자료 갱신에는 인터넷이 필요합니다. 로그인과 외부 서버 저장은 사용하지 않습니다.

## 사용 순서

1. **출장 정보**에서 출장자, 지급등급, 목적, 기간, 장소, 출장 승인 여부를 입력합니다. 세부 지급기준과 비고는 접힌 항목에서 작성합니다.
2. **국내 출장 / 국외 출장**에서 방문 국가·도시를 선택하고 일정을 생성합니다. 각 날짜의 실제 업무·이동·숙박을 수정합니다.
3. 운임·숙박·증빙을 입력합니다. 국외 정액은 USD 현찰 구매 환율, 국외 카드 숙박은 실제 청구 원화액과 신청 당시 현지 환율을 입력합니다.
4. 필요한 경우 **특수 여비**에서 준비금, 이전비, 가족여비, 상시출장 여비를 추가합니다.
5. **정산서**에서 확정액·미확정액·기지급액·반납액을 확인하고 Excel·Word를 다운로드합니다. 산식과 미확정 사유는 **계산 근거 / 확인 사항** 탭에 있습니다.
6. **출장 저장**을 누릅니다. **보관함**에서 검색·불러오기·수정·복사·삭제·정산서 재생성이 가능합니다.

자세한 입력 방법은 [사용 설명서](docs/사용설명서.md)를 참고하세요. 샘플은 [예시 입력](examples/국내출장_예시.json)이며 실제 개인정보나 실제 환율을 포함하지 않습니다.

## 계산과 법령 자료

- `Decimal`로 계산합니다. 화면·Excel·Word가 **같은 `Result` 객체**를 사용합니다.
- 국내 근무지 내/외, 왕복 12km 경계, 2km 이내 실비, 4시간 기준, 공무용 차량 감액을 처리합니다.
- 일반 국내 일비·식비는 각각 25,000원입니다. 숙박비는 제2호 서울 100,000원·광역시 80,000원·기타 70,000원의 날짜별 상한을 합산해 출장 전체로 정산합니다.
- 국외 지급등급 5개 × 지역등급 4개의 전체 지급표, 별표에 열거된 국가 164개와 도시 예외 12개를 반영했습니다. 싱가포르는 도시 예외에 포함됩니다.
- 미열거 국가는 가장 가까운 **수도**가 있는 열거 국가와 거리 근거를 입력합니다. 임의 등급을 부여하지 않습니다.
- 국외 숙박은 현지통화/USD 상한과 카드사 실제 원화 청구액을 함께 비교합니다. 현지 상한 이내 카드 결제 시 원화 상한만으로 잘못 삭감하지 않습니다.
- 정액용 USD 원화환율의 소수점은 절사하고, 정액 합계의 10원 미만을 절사합니다. 환율을 자동으로 가정하지 않습니다.
- 무료 숙박·기관 직접결제·할인·타 기관 지원·초과지출·승인 대기·기지급액을 구분합니다.
- 장기체재 기산일수는 입력값입니다. 임시 타지역 출장과 출발일을 반영해 수정해야 합니다.

## 정산서

Excel은 요약·원본 입력·일정·교통·숙박·일비식비·기타경비·산식근거·정산검토의 **9개 시트**로 구성합니다. 숫자 형식, 필터, 고정 헤더, A4 인쇄영역, 반복 인쇄 헤더와 합계 강조를 적용했습니다. 최종 금액은 숫자 값으로 저장하고 단순 합계 수식에는 캐시를 함께 저장합니다.

Word는 출장 개요·일정·정산 총괄·항목별 산식·조정·증빙·법령 근거와 **모든 원본 입력 부록**을 포함합니다. A4, 한글 동아시아 글꼴, 표 헤더 반복, 행 나눔 방지, 페이지 번호와 공식 출처 링크를 적용했습니다.

미입력은 0원과 다르게 표시합니다. `증빙 필요`, `승인 필요`, `근거 확인 필요`인 금액은 확정 청구액에서 제외합니다. 미확정 금액을 산정할 수 없는 경우에는 숫자 합계와 별도로 사유를 표시합니다.

## 코드 구성

```text
app.py                  Streamlit 실행 진입점
travel/models.py        공통 입력·계산 결과와 Decimal 처리
travel/rules.py         법령 시행일과 국가·도시 조회
travel/domestic.py      국내 및 근무지 내, 장기체재, 마일리지
travel/overseas.py      국외 정액과 원화 절사
travel/expenses.py      실비 교통·숙박과 초과지출
travel/special.py       준비금·이전비·가족여비·상시출장
travel/engine.py        공통 계산 진입점
travel/storage.py       SQLite와 저장 당시 계산 보존
travel/report.py        공통 보고 데이터와 원본 입력 전개
travel/excel.py         openpyxl Excel 생성
travel/word.py          python-docx Word 생성
travel/ui.py            한국어 화면
travel/data/            법령 자료집 및 공식 별표 원문
docs/                   한글 설명서와 구현 범위
tests/                  주요 법정 경계와 문서·저장 통합 사례
```

개인 기록은 `local_data/trips.sqlite3`에 생성되며 Git에서 제외합니다. 설정 화면에서 JSON 또는 SQLite 백업을 내려받을 수 있습니다. 증빙 파일 자체는 업로드하지 않고 보관위치와 문서번호를 기록합니다.
