# 바른여비

국가공무원의 국내·국외 출장비를 계산하고 **Excel과 편집 가능한 Word 정산서**를 만드는 개인용 Streamlit 앱입니다. 한 출장 또는 여러 출장을 묶어 계산·저장·출력할 수 있습니다. 입력 변경 시 재계산하며, 입력·계산 결과·환율·법령 자료집을 SQLite에 함께 저장합니다.

**자동 계산이 가능한 항목과 기관 판단이 남는 항목을 구분한 첫 배포본입니다. 모든 법정 특례의 자동 판정까지 완료한 제품은 아닙니다.** 퇴직·휴직·국외 사망자 여비, 기관별 특례협의, 과거 자료가 없는 기간 등은 `근거 확인 필요`로 표시합니다. [지원 범위](docs/지원범위.md)에 세부 상태를 공개합니다.

## 실행

Python **3.12 이상**을 설치한 뒤 저장소 폴더에서 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows PowerShell은 활성화 명령 대신 아래처럼 실행할 수 있습니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 [로컬 앱](http://localhost:8501)을 엽니다. 의존성 설치 후에는 **기본 계산·저장·문서 생성에 인터넷이 필요하지 않습니다.** **출발일 기준 유가 자동 조회**, 법령 원문 링크 열기와 자료 갱신에는 인터넷이 필요합니다. 로그인과 외부 서버 저장은 사용하지 않습니다.

## 바로 계산하기

1. **국내 / 국외**를 선택하고 출발일·복귀일, 출장 범위와 지급 등급을 확인합니다.
2. 숙박비와 왕복 교통비를 **전체 합계**로 입력합니다. 숙박 지역은 숙박이 있는 국내 출장에만 표시됩니다. 국외는 국가·도시·USD 원화환율을 입력합니다.
3. 같은 화면 아래에 **예상 출장비와 일비·식비·숙박비·교통비**가 바로 표시됩니다.

이름·소속·출장명·목적은 선택 입력입니다. 자가용은 교통수단에서 선택하면 대중교통 운임 또는 연료비 방식으로 계산합니다. 연료비는 출발일·유종에 맞는 오피넷 전국 평균 유가를 자동 반영합니다. 지급 등급은 기본 화면에 표시합니다. 공무용 차량·기지급액·날짜별 입력·정산서 정보는 결과 아래 `상세 입력·정산`으로 모았습니다. 당일 출장은 숙박 입력을, 근무지 내 출장은 숙박·별도 교통수단 입력을 표시하지 않습니다. 일정은 자동 생성되며 메뉴 이동이나 계산 버튼이 필요하지 않습니다. 거리·운임·도시·환율 등 총액 계산에 필요한 값이 비어 있으면 그 항목을 안내하고 산출 가능한 금액은 `입력한 항목 합계`로 표시합니다.

출장 1건도 결과 바로 아래의 **계산 저장 / Excel 다운로드 / Word 다운로드**를 사용할 수 있습니다. 탭을 열 필요가 없습니다. `상세 입력·정산 → 계산 내역`에서는 입력 백업과 계산식을 확인합니다. 오른쪽 위 `내 기록`에서 저장한 계산을 불러옵니다. 미확정 금액이 포함된 예상액과 승인·증빙을 반영한 확정 청구액을 구분합니다. 직접 입력한 국외 환율은 예상 계산에만 사용합니다.

일정·숙박·교통·증빙 표는 편집 중 원본과 높이를 고정하여 Enter 입력 때 값이 사라지거나 표가 재생성되는 문제를 수정했습니다. 자세한 조건은 [사용 설명서](docs/사용설명서.md)에 있습니다. [예시 입력](examples/국내출장_예시.json)은 실제 개인정보나 실제 환율을 포함하지 않습니다.

## 금액 입력과 여러 출장 계산

금액 입력란은 숫자를 입력하는 동안 `1234123 → 1,234,123`으로 표시합니다. 쉼표가 있는 금액을 붙여넣을 수 있으며, 소수 단가·환율은 필요한 자릿수를 유지합니다. **Enter 또는 입력란 밖 클릭**으로 계산에 반영합니다. 내부 계산·저장 값에는 표시용 쉼표를 넣지 않습니다.

1. 첫 출장의 날짜·금액을 입력한 뒤 상단 **출장 추가**를 누릅니다.
2. 추가된 출장의 필수 항목을 입력합니다. **입력할 출장**에서 앞선 출장으로 돌아가 수정할 수 있습니다. 성명·소속·지급 등급은 추가할 때 가져오며 날짜와 비용은 별도로 입력합니다.
3. 결과에서 **전체 합계와 출장별 금액**을 확인하고 **일괄 저장 / 전체 Excel / 전체 Word**를 선택합니다.
4. 저장한 묶음은 **내 기록**에서 다시 불러옵니다. `상세 입력·정산 → 계산 내역`에서 묶음 이름을 정하거나 전체 JSON 백업을 내려받을 수 있습니다.

일괄 Excel은 전체 요약·항목별 내역·원본 입력·정산 확인의 4개 시트이며, Word는 전체 요약 다음에 출장별 정산서를 이어 붙입니다. 각 출장의 법령 자료집·유가·환율·증빙 상태를 따로 보존합니다. 확정 청구액과 반납예정액은 각 출장에서 기지급액을 차감한 뒤 합산하며, 서로 다른 출장의 기지급액을 상계하지 않습니다. 파일은 다운로드를 누를 때 생성하여 출장 입력을 지연시키지 않습니다.

잘못 입력한 출장은 예상 출장비 영역의 해당 카드에서 **수정**을 누르면 그 출장의 입력란으로 이동합니다. 카드의 **삭제**를 누르면 해당 출장만 현재 계산에서 빠지고 전체 합계·출력에도 즉시 반영됩니다. 출장 1건일 때도 예상 출장비 옆에 두 버튼을 표시합니다. 마지막 출장을 삭제하면 새 입력을 엽니다. 상단에는 **입력할 출장 / 출장 추가**를 유지하며, 수정한 기록은 **계산 저장 / 일괄 저장**으로 저장합니다.

저장된 출장은 **내 기록 → 불러와 수정**으로 편집합니다. **기록 삭제**는 저장된 기록을 삭제합니다. 개별 출장 삭제 시 저장된 묶음에서도 해당 출장과 금액을 제외하며, 빈 묶음은 삭제합니다. 묶음 기록만 삭제하면 개별 출장 기록은 유지합니다. 예상 출장비 카드의 **삭제**는 저장된 기록까지 삭제하지 않습니다.

## 계산과 법령 자료

- `Decimal`로 계산합니다. 화면·Excel·Word가 **같은 `Result` 객체**를 사용합니다.
- 국내 근무지 내/외, 왕복 12km 경계, 2km 이내 실비, 4시간 기준, 공무용 차량 감액을 처리합니다.
- 일반 국내 일비·식비는 각각 25,000원입니다. 숙박비는 제2호 서울 100,000원·광역시 80,000원·기타 70,000원의 날짜별 상한을 합산해 출장 전체로 정산합니다.
- 국외 지급등급 5개 × 지역등급 4개의 전체 지급표, 별표에 열거된 국가 164개와 도시 예외 12개를 반영했습니다. 싱가포르는 도시 예외에 포함됩니다.
- 미열거 국가는 가장 가까운 **수도**가 있는 열거 국가와 거리 근거를 입력합니다. 임의 등급을 부여하지 않습니다.
- 국외 숙박은 현지통화/USD 상한과 카드사 실제 원화 청구액을 함께 비교합니다. 현지 상한 이내 카드 결제 시 원화 상한만으로 잘못 삭감하지 않습니다.
- 정액용 USD 원화환율의 소수점은 절사하고, 정액 합계의 10원 미만을 절사합니다. 환율을 자동으로 가정하지 않습니다.
- 무료 숙박·기관 직접결제·할인·타 기관 지원·초과지출·승인 대기·기지급액을 구분합니다.
- 장기체재 기산일수는 입력값입니다. 임시 타지역 출장과 출발일을 반영해 수정해야 합니다.

## 정산서

여러 출장을 입력하면 전체 예상 출장비 아래에 출장별 카드가 자동으로 나타납니다. 각 카드에는 출장명·기간·총액과 일비·식비·숙박비·교통비 금액만 간결하게 표시합니다. 날짜별 계산식과 정산 상태는 ‘상세 입력·정산 → 계산 내역’에서 선택한 출장별로 볼 수 있습니다.

Excel은 인사혁신처 제226호의 공식 신청서와 계산 보조 시트를 구분합니다. 개별 출력은 공식 신청서를 앞에 배치하고 기존 9개 계산 시트를 보존합니다. 일괄 출력은 전체 요약 다음에 출장별 공식 신청서, 항목별 금액·계산 근거·원본 입력·정산 확인·출장별 비용 요약을 제공합니다. 공동숙박 시 사람별 신청서와 분담 시트를 추가합니다. 금액은 숫자 값이며 단순 합계 수식에는 캐시를 함께 저장합니다.

Word는 공식 신청서 뒤에 출장 개요·일정·정산 총괄·항목별 산식·조정·증빙·법령 근거와 **모든 원본 입력 부록**을 별첨으로 배치합니다. A4 본문 너비에 맞춰 표의 격자·셀 너비·여백을 통일하고, 한글 글꼴·표 헤더 반복·페이지 번호·공식 출처 링크를 적용했습니다.

공식 서식은 국내 **별지 제3호 ‘국내여비 정산 신청서’**, 국외 **별지 제7호 ‘국외여비(식비·숙박비·준비금) 정산 신청서’**를 기준으로 항목·병합 구조·신청 문구·서명란을 재현합니다. 원문 및 적용 범위는 [출력 서식 안내](docs/출력서식.md)에 정리했습니다.

미입력은 0원과 다르게 표시합니다. `증빙 필요`, `승인 필요`, `근거 확인 필요`인 금액은 확정 청구액에서 제외합니다. 미확정 금액을 산정할 수 없는 경우에는 숫자 합계와 별도로 사유를 표시합니다.

## 공동 출장자는 숙박비만 함께 정산

국내·근무지 외 출장에서 **공동 출장자 숙박비 함께 정산**을 켜고, 본인을 포함한 숙박 인원을 입력합니다. 숙박비에는 객실 영수증 총액을 한 번만 입력합니다. 동행자의 이름은 선택 입력이며 지급 등급은 ‘동행자 이름·등급’에서 사람별로 바꿀 수 있습니다.

예를 들어 거제시(기타 지역), 제2호 두 명, 3박에 객실 총액 236,634원이면 각각 118,317원을 분담합니다. 각자의 3박 상한 210,000원 이내이므로 숙박 예상 인정액 합계는 236,634원입니다. 원 단위 나머지는 마지막 분담자에게 배정하므로 합계가 달라지지 않습니다. **공동 출장자의 일비·식비·교통비는 추가하지 않습니다.** 동행자의 숙박비를 포함한 대표 정산이며 본인 혼자 쓴 숙박비로 기록하지 않습니다.

간편 입력은 같은 기간·숙박지역에 함께 숙박한 공무 출장자를 기준으로 합니다. 가족·사적 동행자는 인원에 넣지 않습니다. 일부 날짜만 동행하거나 실제 분담액이 다르면 ‘날짜별로 다르게 입력’의 숙박 표에서 정산 대상별 날짜·분담 지출액을 조정합니다. 같은 정산대상ID의 숙박비끼리 상한을 적용합니다. 국외 공동숙박과 별도의 숙박비 절감 보상은 자동 계산 범위에 포함하지 않습니다.

화면의 ‘숙박비 분담 내역’, 개별·일괄 Excel·Word, 저장 기록과 JSON 백업에 사람별 분담액·등급·상한·인정액을 보존합니다. 영수증 총액은 분담액 합계와 동일하며 다른 문서나 공동 출장자의 청구에 같은 숙박비를 중복 기재하지 않아야 합니다.

## 코드 구성

개인 기록은 `local_data/trips.sqlite3`에 생성되며 Git에서 제외합니다. 계산 내역에서 JSON 백업을 내려받을 수 있습니다. 증빙 파일 자체는 업로드하지 않고 보관위치와 문서번호를 기록합니다.

## 개발 실행

화면 없이 동일한 엔진으로 예시 정산서를 생성할 수도 있습니다. 출력은 Git에서 제외되는 로컬 폴더에 저장됩니다.

```bash
python scripts/export_trip.py examples/국내출장_예시.json
```

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

공식 지침의 공적 마일리지 사례, 국외 할인정액 환산 사례, 개인카드 숙박 정산 사례와 법정 경계값을 사용합니다. 이 저장소의 자료가 바뀌지 않은 상태에서 자동으로 최신 법령을 적용한다고 표시하지 않습니다. 갱신 절차는 [계산 기준 문서](docs/법령과계산기준.md)에 있습니다.
